## 📋 Sobre o Projeto

O **Pit Wall** nasceu com o objetivo de oferecer uma experiência visual limpa e direta para fãs de velocidade, trazendo dados organizados como se você estivesse no muro dos boxes acompanhando a telemetria e as estratégias da pista.

### ✨ Funcionalidades
* **Interface Responsiva:** Adaptada para visualização tanto em desktop quanto em dispositivos móveis.
* **Design Temático:** Estilização inspirada no ambiente de corrida e telemetria.
